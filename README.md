# Тренировки — мобильное PWA

Дневник тренировок с учётом цикла: тренировки А и Б, фазы цикла, рекомендации по весу,
история и резервные копии. Работает офлайн, без сервера и регистрации — все данные
остаются на устройстве (IndexedDB).

Это перенос старой одностраничной версии (`reference/Trenirovki_dnevnik_1.html`) в
устанавливаемое приложение. Логика тренировок, цикла и рекомендаций перенесена 1:1,
тексты — дословно.

## Что умеет

**Сегодня**
- Тренировки А и Б (одни и те же упражнения, подходы, диапазоны повторений, отдых, тип нагрузки).
- Очередь: следующая тренировка — противоположная последней сохранённой (первая — А).
- Кольцо-диаграмма дня цикла, фаза, режим (прогресс / поддержка / облегчённый).
- Рекомендация по весу по каждому упражнению (ветки «первый раз», резинка, облегчённый −10 %,
  этап освоения, верхняя граница повторений).
- «Прошлый раз» — вес и повторения прошлой тренировки по этому упражнению.
- Ввод подходов (вес/резинка × повторения) с подстановкой рекомендованного веса.
- Самочувствие (хорошо / нормально / плохо): «Плохо» переводит тренировку в облегчённый режим.
- Заметка к тренировке, «Сохранить тренировку», «Очистить введённое».
- Черновик ввода сохраняется автоматически и живёт до конца дня.

**История**
- Список тренировок с фазой и днём цикла, самочувствием, подходами и заметкой.
- Удаление — вторым нажатием по кнопке.
- График рабочего веса по упражнению; цвет точки — фаза цикла в день тренировки.

**Цикл**
- Начало последней менструации, длина цикла (20–45 дней), длительность менструации (2–9 дней).
- Кнопка «Менструация началась сегодня», список отмеченных начал, средняя длина цикла
  по последним трём интервалам 18–45 дней с кнопкой «Применить».
- Текущий цикл: диапазоны фаз с датами и советами, прогноз следующей менструации.
- Тема оформления: системная / светлая / тёмная.
- Резервная копия: сохранить в файл, скопировать текстом, загрузить из файла.

**Техника** — правила техники, прогрессия, запас повторений, учёт цикла (текст из старой версии).

## Стек

Vite + React 19 + TypeScript (strict) + Dexie (IndexedDB) + vite-plugin-pwa,
тесты Vitest + fake-indexeddb + @testing-library/react + jsdom.

```
src/
  domain/    чистые функции: тренировки, цикл, рекомендации, форматирование
  storage/   Dexie (SCHEMA_VERSION), операции с данными, резервные копии
  ui/        экраны Today / History / Cycle / Tech, компоненты, стили
tests/       domain, storage, ui
```

## Запуск

```bash
npm install
npm run dev        # разработка, http://localhost:5173
npm test           # тесты (vitest run)
npm run typecheck  # проверка типов (tsc -b)
npm run build      # сборка в dist/ (tsc -b && vite build)
npm run preview    # локальный просмотр собранной версии
npm run icons      # перегенерировать иконки (public/icons)
```

Сборка делается с `base: './'` — папку `dist/` можно положить в любую подпапку
статического хостинга (например, GitHub Pages). Адреса внутри приложения — hash-роуты:
`#/today`, `#/history`, `#/cycle`, `#/tech`.

## Установка на телефон

1. Открыть адрес приложения в браузере телефона (лучше Chrome на Android или Safari на iOS).
2. «Установить приложение» / «На экран „Домой“» — в меню браузера.
3. Открывать можно из иконки на рабочем столе: приложение запускается без адресной строки.
4. После первого открытия service worker кэширует приложение — дальше оно работает офлайн.
   Если вышла новая версия, в приложении появится баннер «Доступна новая версия — обновить».

Данные хранятся только на этом устройстве. Если очистить данные сайтов в браузере или
сменить браузер, записи пропадут — поэтому иногда делайте копию.

## Перенос записей из старой страницы

Старая версия (одна HTML-страница) хранила данные в `localStorage` по адресу старой страницы,
поэтому напрямую перенести их в новое приложение нельзя. Перенос делается через файл копии:

1. На старой странице: **Цикл → Сохранить копию в файл** (получится `trenirovki-kopiya-ДД.ММ.ГГГГ.json`).
2. В новом приложении: **Цикл → Загрузить копию из файла** и выбрать этот файл.
3. Приложение покажет, сколько записей загружено.

Формат копии совместим в обе стороны: `{ app: "trenirovki", v: 1, config, sessions }`.
Тренировки сливаются по `id` — уже сохранённые записи не перезаписываются, повторный импорт
одной и той же копии дублей не создаёт. Чужой или повреждённый файл отклоняется с понятным сообщением.

## Иконки

`scripts/make_icons.mjs` рисует иконки (гантель в фиолетовой гамме) без внешних зависимостей
и пишет PNG в `public/icons/`: 192, 512, maskable 512, apple-touch-icon 180 и SVG.
После изменения скрипта выполните `npm run icons`.

## Тесты

```bash
npm test
```

- `tests/domain/cycle.test.ts` — фазы/режимы/расчёт цикла (L=28, L=24, L=35), прогноз, дата в будущем,
  ограничения настроек, средняя длина цикла.
- `tests/domain/rec.test.ts` — все ветки рекомендаций по весу для штанги, гантелей, доп. веса и резинки.
- `tests/storage/storage.test.ts` — сохранение и удаление тренировки, черновик, импорт копии формата
  старой страницы без дублей, отказ на чужом файле.
- `tests/ui/today.test.tsx` — тренировка, сохранённая на «Сегодня», появляется в «Истории»;
  открытие всех разделов; первый запуск просит указать дату.
- `tests/ui/regression.test.tsx` — регрессия на запись внутри `useLiveQuery` (Dexie отвечает
  `ReadOnlyError`, приложение показывало белый экран): запуск на пустой базе, настоящая точка входа
  `main.tsx`, отсутствие ошибок в консоли и отсутствие записей во время подписки, а также
  ErrorBoundary вместо белого экрана при ошибке отрисовки.

### Важно при доработке

Внутри `useLiveQuery` нельзя выполнять записи: Dexie бросает `ReadOnlyError`
(«Readwrite transaction in liveQuery context»), а ошибка пробрасывается в render — React
размонтирует дерево, и приложение показывает белый экран. Все подписки в `src/ui/data.ts`
только читают; запись настроек по умолчанию создаётся один раз при старте
(`ensureConfig()` в `src/main.tsx`).
