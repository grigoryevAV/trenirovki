# Тренировки — мобильное PWA

Дневник тренировок с учётом цикла: тренировки А и Б, фазы цикла, рекомендации по весу,
история и резервные копии. Работает офлайн, без сервера и регистрации — все данные
остаются на устройстве (IndexedDB).

Это перенос старой одностраничной версии (`reference/Trenirovki_dnevnik_1.html`) в
устанавливаемое приложение. Логика тренировок и цикла перенесена 1:1; нагрузки теперь
планируются двойной прогрессией по факту выполненного (см. «Прогрессия нагрузок»).

## Что умеет

**Сегодня**
- Тренировки А и Б (одни и те же упражнения, подходы, диапазоны повторений, отдых, тип нагрузки).
- Очередь: следующая тренировка — противоположная последней сохранённой (первая — А).
- Рекомендация по каждому упражнению: вес, цели повторений и короткое пояснение.
  Влияние режима дня отражено только здесь, без названий фаз и дня цикла:
  облегчённый день — «Облегчённый день: …», режим поддержки с возможной прибавкой —
  «Можно +2,5 кг, если сегодня легко», окно прогресса — без пометок.
- «Прошлый раз» — вес и повторения прошлой тренировки по этому упражнению.
- Ввод подходов (вес/резинка × повторения): вес подставляется по рекомендации, в поле повторенов
  стоит подсказка «цель 11», над подходами — строка «Цель: 40 кг × 11 · 10 · 9 — запас 3».
- Самочувствие (хорошо / нормально / плохо): «Плохо» переводит тренировку в облегчённый режим.
- Заметка к тренировке; «Очистить введённое» — с подтверждением вторым нажатием.
- Кнопка «Сохранить тренировку» закреплена внизу экрана над панелью вкладок (safe-area учтён).
- Черновик ввода сохраняется автоматически (запись с задержкой 250 мс, последнее значение
  записывается при сохранении тренировки и при уходе со страницы) и живёт до конца дня.
- Если дата начала менструации не указана — компактная строка с полем даты (цикл влияет только на режим).

**История**
- Список тренировок с самочувствием, подходами и заметкой.
- Удаление — вторым нажатием по кнопке.
- График рабочего веса по упражнению (точки одного цвета).

**Цикл** (единственное место, где цикл показывается — на «Сегодня» и в «Истории» его нет)
- Кольцо-диаграмма дня цикла, фаза и режим.
- Начало последней менструации, длина цикла (20–45 дней), длительность менструации (2–9 дней).
- Кнопка «Менструация началась сегодня», список отмеченных начал, средняя длина цикла
  по последним трём интервалам 18–45 дней с кнопкой «Применить».
- Текущий цикл: диапазоны фаз с датами и советами, прогноз следующей менструации.
- Настройки прогрессии: шаг прибавки веса для каждого упражнения.
- Тема оформления: системная / светлая / тёмная.
- Резервная копия: сохранить в файл, скопировать текстом, загрузить из файла.

## Прогрессия нагрузок

Цель на сегодня считается по факту выполненного — двойная прогрессия (вес + повторения).
База — последняя тренировка того же типа (А/Б) с этим упражнением.

- **Все запланированные подходы на верхней границе одним весом** → вес прибавляется на шаг
  упражнения, цель повторений — с нижней границы («начинайте с 6»).
- **Иначе** → вес рабочий (максимальный из прошлых), цель повторений по подходу = прошлые + 1,
  не выше верхней границы; если подхода не было — нижняя граница.
  Пример: 3 × 8–12, прошлый раз 10, 9, 8 → цели 11, 10, 9.
- **Застой** (две последние тренировки одним весом, сумма повторений не выросла) → вес −10 %
  с округлением к шагу и текст «Два раза без прогресса — снизьте вес на 10 % и наберите заново».
  Облегчённые тренировки в анализ застоя не входят.
- **Режим цикла и самочувствие**: в окне прогресса — прибавка; в режиме поддержки — вес прежний,
  в тексте «Можно +2,5 кг, если сегодня легко»; в облегчённом режиме — без прибавки
  (штанга −10 %, гантели и доп. вес — тот же вес), цели повторений не повышаются.
- **Этап освоения** (первые 4 тренировки) — вес можно прибавлять на шаг, техника важнее.
- **Запас повторений** подписан в строке цели: недели 1–2 «запас 4–5», 3–6 «запас 3»,
  с 7-й недели «запас 2»; для приседа и румынской тяги добавляется «не до отказа»,
  в облегчённом режиме — «запас 3–4».
- **Шаги прибавки** по умолчанию: штанга (присед, румынская тяга) +2,5 кг, ягодичный мост +5 кг,
  гантели +1 кг на гантель (в тексте — «следующие по весу гантели»), гиперэкстензия +2,5 кг,
  резинка — «тоньше». Любой шаг меняется
  в «Цикл → Настройки прогрессии», хранится в настройках и входит в резервную копию.

## Стек

Vite + React 19 + TypeScript (strict) + Dexie (IndexedDB) + vite-plugin-pwa,
тесты Vitest + fake-indexeddb + @testing-library/react + jsdom.

```
src/
  domain/    чистые функции: тренировки, цикл, прогрессия, форматирование
  storage/   Dexie (SCHEMA_VERSION), операции с данными, резервные копии
  ui/        экраны Today / History / Cycle, компоненты, стили
tests/       domain, storage, ui
```

## Запуск

```bash
npm install
npm run dev        # разработка, http://localhost:5173
npm test           # тесты (vitest run)
npm run typecheck  # проверка типов (tsc -b)
npm run build      # сборка в dist/ (tsc -b && vite build)
npm run preview    # локальный просмотр собранной версии
npm run icons      # перегенерировать иконки (public/icons)
```

Сборка делается с `base: './'` — папку `dist/` можно положить в любую подпапку
статического хостинга (например, GitHub Pages). Адреса внутри приложения — hash-роуты:
`#/today`, `#/history`, `#/cycle`. Старый адрес `#/tech` открывает «Сегодня».

## Установка на телефон

1. Открыть адрес приложения в браузере телефона (лучше Chrome на Android или Safari на iOS).
2. «Установить приложение» / «На экран „Домой“» — в меню браузера.
3. Открывать можно из иконки на рабочем столе: приложение запускается без адресной строки.
4. После первого открытия service worker кэширует приложение — дальше оно работает офлайн.
   Если вышла новая версия, в приложении появится баннер «Доступна новая версия — обновить».

Данные хранятся только на этом устройстве. Если очистить данные сайтов в браузере или
сменить браузер, записи пропадут — поэтому иногда делайте копию.

## Перенос записей из старой страницы

Старая версия (одна HTML-страница) хранила данные в `localStorage` по адресу старой страницы,
поэтому напрямую перенести их в новое приложение нельзя. Перенос делается через файл копии:

1. На старой странице: **Цикл → Сохранить копию в файл** (получится `trenirovki-kopiya-ДД.ММ.ГГГГ.json`).
2. В новом приложении: **Цикл → Загрузить копию из файла** и выбрать этот файл.
3. Приложение покажет, сколько записей загружено.

Формат копии совместим в обе стороны: `{ app: "trenirovki", v: 1, config, sessions }`.
Тренировки сливаются по `id` — уже сохранённые записи не перезаписываются, повторный импорт
одной и той же копии дублей не создаёт. Чужой или повреждённый файл отклоняется с понятным сообщением.

## Иконки

Иконка приложения — рисунок владелицы (`art/icon-source.png`). PNG-иконки (192, 512, maskable 512,
apple-touch-icon 180) и SVG-иконка генерируются скриптом `scripts/make_icons.py`
(нужны Python и Pillow): `npm run icons` перерисует их.

`scripts/make_icons.mjs` — запасной генератор без внешних зависимостей (гантель в фиолетовой
гамме эталона). Сейчас не используется: основной источник иконок — рисунок владелицы,
запуск `npm run icons` его не затрагивает.

## Тесты

```bash
npm test
```

- `tests/domain/cycle.test.ts` — фазы/режимы/расчёт цикла (L=28, L=24, L=35), прогноз, дата в будущем,
  ограничения настроек, средняя длина цикла.
- `tests/domain/progression.test.ts` — все ветки прогрессии: цели повторений (включая пример
  10, 9, 8 → 11, 10, 9), верхняя граница (в т.ч. «пирамида» 30 / 32,5 / 32,5), шаги из настроек,
  застой (есть / нет / облегчённые тренировки не учитываются), режимы progress / hold / light,
  этап освоения, резинка, границы недель и подписи запаса повторений.
- `tests/domain/draft.test.ts` — слияние черновика: введённое в этой сессии не перетирается
  загруженным из базы.
- `tests/domain/rec.test.ts` — `rec()` как обёртка над прогрессией, очередь тренировок,
  «Прошлый раз», описания упражнений.
- `tests/storage/storage.test.ts` — сохранение и удаление тренировки, черновик, шаги прогрессии
  в настройках и в резервной копии, импорт копии формата старой страницы без дублей,
  отказ на чужом файле, дополнение старого конфига без шагов.
- `tests/ui/today.test.tsx` — тренировка, сохранённая на «Сегодня», появляется в «Истории»;
  вкладки «Техника» нет и `#/tech` открывает «Сегодня»; на основных экранах нет фаз и дня цикла;
  клавиатура для резинки — текстовая; черновик не теряет введённое; цель повторений видна
  в подсказке поля и в строке цели; строка рекомендации скрыта в обычном случае;
  «Очистить введённое» спрашивает подтверждение.
- `tests/ui/regression.test.tsx` — регрессия на запись внутри `useLiveQuery` (Dexie отвечает
  `ReadOnlyError`, приложение показывало белый экран): запуск на пустой базе, настоящая точка входа
  `main.tsx`, отсутствие ошибок в консоли и отсутствие записей во время подписки, а также
  ErrorBoundary вместо белого экрана при ошибке отрисовки.

### Важно при доработке

Внутри `useLiveQuery` нельзя выполнять записи: Dexie бросает `ReadOnlyError`
(«Readwrite transaction in liveQuery context»), а ошибка пробрасывается в render — React
размонтирует дерево, и приложение показывает белый экран. Все подписки в `src/ui/data.ts`
только читают; запись настроек по умолчанию создаётся один раз при старте
(`ensureConfig()` в `src/main.tsx`).
